# User Management System

## Tech Stack
- React JS
- Axios
- Flask REST API
- MySQL

## Backend Setup
1. Open the backend folder.
2. Create and activate a virtual environment.
3. Install dependencies:
   pip install -r requirements.txt
4. Open app.py and replace YOUR_MYSQL_PASSWORD.
5. Run:
   python app.py

## Database Setup
Run user_management.sql in MySQL Workbench.

## Frontend Setup
Use your existing Vite React frontend, install Axios:
npm install axios

Replace src/App.jsx with the provided App.jsx.

Run:
npm run dev
